Scan Layers Team

Adaptive multi-layer phishing detection

One URL. Four independent lenses.

Each layer of the framework examines the same website on its own terms – its name, its code, how it looks, and the infrastructure behind it – and reports back separately.

>_

Research prototype. Do not submit links that contain passwords, tokens or personal data. Results support human judgement – "legitimate" is a model output, not a guarantee of safety.

Layer agreement

A simple count of the layers that answered. The group has not adopted a combined decision rule, so this is not a single verdict.

The four layers

  1. C1

    Domain name

    Typosquatting rules and a LightGBM + character n-gram model judge the registered domain alone, before any page is fetched.

  2. C2

    Page code

    A frozen LightGBM model reads 106 static HTML/JavaScript features – forms, credential cues, scripts and links – from the page source.

  3. C3

    Visual appearance

    Two EfficientNetV2B0 CNNs score a screenshot of login or general pages, with Grad-CAM explanations.

  4. C4

    Infrastructure

    DNS, RDAP/WHOIS, TLS and hosting intelligence feed a tuned LightGBM model, alongside a separate reputation lookup.
