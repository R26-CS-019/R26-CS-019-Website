How it works

Four evidence layers, one decision

  1. C1

    Domain name

    Typosquatting rules and a LightGBM + character n-gram model judge the registered domain alone, before any page is fetched.

  2. C2

    Page code

    A frozen LightGBM model reads 106 static HTML and JavaScript features – forms, credential cues, scripts and links.

  3. C3

    Visual appearance

    Two EfficientNetV2B0 CNNs score a screenshot of login or general pages.

  4. C4

    Infrastructure

    DNS, RDAP/WHOIS, TLS and hosting data feed a tuned LightGBM model, next to a separate reputation lookup.
